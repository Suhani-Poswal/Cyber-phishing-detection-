# 🔐 Phishing Detection Tool

## 📌 Overview
The Phishing Detection Tool is a web-based cybersecurity application designed to identify whether a given website URL is safe, suspicious, or a phishing attempt. It helps users avoid malicious websites and protects them from online fraud.

---

## 🎯 Objective
The main objective of this project is to improve cybersecurity awareness by providing a simple and effective tool that analyzes URLs and detects potential phishing threats.

---

## 🚨 Problem Statement
Many users are unable to identify phishing websites, which can lead to serious issues such as data theft, financial fraud, and identity misuse. This project aims to solve this problem by analyzing URL patterns and alerting users about suspicious websites.

---

## ⚙️ Features
- 🔍 URL Structure Analysis  
- ⚡ Real-Time Detection  
- 🚦 Safe / Suspicious / Phishing Results  
- 🎨 Attractive & Interactive UI  
- ⏳ Loading Animation  
- 🧠 Keyword-Based Detection  

---

## 🛠️ Technology Stack
- **HTML** – Structure of the webpage  
- **CSS** – Styling and UI design  
- **JavaScript** – Logic and functionality  
- **GitHub** – Version control and hosting  

---

## 🚀 How It Works
1. User enters a website URL  
2. The system analyzes the URL using predefined rules  
3. A score is generated based on suspicious patterns  
4. The result is displayed as:
   - ✅ Safe  
   - ⚠️ Suspicious  
   - ❌ Phishing
